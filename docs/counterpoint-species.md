# 第2〜5種の採点範囲と独立確認

確認日: 2026-10-10。第1種の既存プロファイル版 `1` は維持し、第2〜5種は `fux_inspired_two_voice_v1` のプロファイル版 `2` で扱います。第1種の判断・出典は [counterpoint-theory.md](counterpoint-theory.md) を参照してください。

対象は2声、長調、固定された全音符の定旋律と、課題が指定する対旋律のリズムです。特定学校の種対位法全体を再現する採点器ではありません。「合格」はこのプロファイルの必須条件を満たすという意味で、旋律の完成度や唯一の正解を示しません。

## 種ごとの扱い

ここでいう第1〜4拍は、画面の4/4の四分音符単位です。二分音符単位で説明する教材の「強拍・弱拍」は、それぞれ画面の第1拍・第3拍に当たります。

| 種 | 指定リズム | 不協和の許容範囲 |
| --- | --- | --- |
| 第2種 | 定旋律1音に二分音符2音。終止は全音符。 | 第1拍は協和。第3拍の不協和は、前後の協和音を同方向の長短2度でつなぐ経過音に限る。刺繍音は許容しない。 |
| 第3種 | 定旋律1音に四分音符4音。終止は全音符。 | 第1拍は協和。第2・3・4拍の経過音、第2・4拍の刺繍音を許容。刺繍音は順次進行で元の音へ戻る。どちらも前後の音が協和であることを要求する。 |
| 第4種 | 冒頭に二分休符。第3拍から次の小節の第1拍へタイで保持する。終止前にタイを解き、最終音は全音符。 | 前の第3拍で協和として準備し、同じ音を次の第1拍へ保持。強拍で不協和になったら、その小節の第3拍へ長短2度下行し協和に解決する。協和のまま保持する箇所も認める。 |
| 第5種 | 課題が指定する二分・四分音符と小節を跨ぐ保持音の混合。 | 経過音・刺繍音・掛留を、それぞれ上記の拍・準備・解決の条件で扱う。 |

第2種の協和と弱拍経過音は [Open Music Theory: Second Species](https://openmusictheory.github.io/secondSpecies.html)、第3種の拍位置と不協和処理は [Third Species](https://openmusictheory.github.io/thirdSpecies.html) に基づきます。第3拍だからという理由だけで、第3種の経過不協和を禁止しません。

掛留は、上声では7–6、4–3、9–8、下声では2–3の型とその複音程を対象とします。音を鳴らし直したものや、解決が上行・跳躍になるものはこの掛留として扱いません。準備・保持・解決の3段階と弱拍の完全音程比較は [Open Music Theory: Fourth Species](https://viva.pressbooks.pub/openmusictheorycopy/chapter/fourth-species-counterpoint/) を参照しています。下声の5–6のように保持時点でも協和する型は、不協和掛留とは区別します。

保持時の音程は通常の完全4度、長短7度、長短9度などに限定し、増4度を4–3掛留の一種として許容しません。途中の同度を避ける方針に合わせ、上声の実際の2–1も対象外です。第4種の終止は、定旋律の第2音→主音に対し、対旋律の主音を前小節から保持して導音へ下行解決し、最後に主音へ進む形を必須とします。

第5種は諸種の音価と掛留を組み合わせる練習です。この実装は [Open Music Theory: Fifth Species](https://viva.pressbooks.pub/openmusictheorycopy/chapter/fifth-species-counterpoint/) が扱う広い範囲のうち、固定リズムで練習できる部分を採用します。

## 入力とタイの意味

- 課題の `noteSlots` が、各入力音のID、開始tick、長さを決めます。休符は課題のリズムで指定され、未入力の音符枠とは別です。
- `ppq = 480`、四分音符480tick、二分音符960tick、1小節1920tickです。第4種のタイを含む音は、第3拍から1920tick続く1つの `Note` として保存します。譜面表示で小節を跨ぐタイに分けても、再発音する別々の音ではありません。
- 採点は対旋律の発音開始だけでなく、定旋律が変わる小節境界も確認します。対旋律を保持していても、定旋律が変われば垂直音程は変わります。
- 定旋律、指定音符枠、プロファイルをサーバー側の原本と照合します。未入力を飛び越えて前後関係を補ったり、固定休符を欠損と判定したりしません。

## 教材との差と未対応の範囲

この版では、入力リズムの自由な編集、途中の休符の追加、短調・教会旋法、カンビアータ、二重刺繍、連続した不協和経過音の特例、八分音符、先取音、装飾した掛留解決を扱いません。第3種で前後に協和を要求する条件は、教材が認める一部の連続不協和より狭い範囲です。第5種を「自由に書ける華麗対位法全般」とは位置付けません。

連続完全音程や直接進行、旋律跳躍の合否と警告の分け方は、第1種の学習方針を基礎にします。完全5度と12度、完全同度と8度・15度はそれぞれ同じ音程族として調べます。途中の実音同度を弱拍でも避ける条件など、教材より狭い選択もあります。課題画面に表示する規則と、そのプロファイル版を実際の判定契約とします。

比較する位置は、隣接する同時発音区間、小節の第1拍同士、第4・5種ではさらに第3拍同士です。同じ完全音程族への同方向進行をエラー、反行を警告とします。間に音がある第1拍同士などの比較では、異なる音程から完全音程へ入ること自体を直接進行のエラーにしません。直接進行は実際に隣り合う発音区間で調べます。

この比較は意図的に限定しています。OMTの第3種では、強拍同士の同族完全音程が2回続く余地がありますが、本版は第2種と共通の強拍比較で判定します。一方、第3種の次小節第1拍の完全音程に対して、前小節の特定の弱拍までさかのぼる教材の追加制限は、現版の採点対象にはしません。規則一覧にない全ての様式上の制限を満たしたと推定しないでください。

教材本文・譜例の転載はせず、音程と進行の原則を参照し、独自の日本語説明と課題を作成しています。Open Music Theory の各ページは CC BY-SA 4.0 表示です。依存ライブラリのライセンスは [既存の理論文書](counterpoint-theory.md#ライブラリの確認) および配布物のライセンス通知を参照してください。

## 自作解答の独立確認

以下は採点器の合否を写す代わりに、音列から垂直音程、進行方向、不協和の前後関係を確認した記録です。音名は中央C = C4。`P` は完全、`M` は長、`m` は短、`A` は増です。検証用解答はサーバー内のテスト素材で、APIの課題一覧に含めず、回答との一致比較にも使いません。

### 第2種

定旋律は C4 D4 E4 F4 G4 E4 D4 C4。対旋律は第1〜7小節が二分音符、第8小節だけ全音符です。

| 小節 | 対旋律 | 垂直音程 |
| --- | --- | --- |
| 1 | G4 A4 | P5 M6 |
| 2 | B4 A4 | M6 P5 |
| 3 | C5 B4 | m6 P5 |
| 4 | D5 C5 | M6 P5 |
| 5 | E5 F5 | M6 m7 |
| 6 | G5 G4 | m10 m3 |
| 7 | A4 B4 | P5 M6 |
| 8 | C5 | P8 |

第5小節第3拍の F5 は E5–F5–G5 の経過音です。G5→G4 の完全8度下行は採用規則で許容する跳躍で、直後の A4 への上行順次進行で回復します。G5 は唯一の最高音。隣接発音と強拍同士の連続完全音程はなく、最後は B4→C5 と D4→C4 の反行終止です。第2〜5小節の強拍で6度族が4回続く点は、教材の旋律・音程配置の助言上、比較の余地があります。このプロファイルは不完全協和音程の連続回数を判定しません。

### 第3種

定旋律は C4 D4 F4 E4 G4 F4 D4 C4。対旋律は第1〜7小節が四分音符、第8小節だけ全音符です。

| 小節 | 対旋律 | 垂直音程 |
| --- | --- | --- |
| 1 | G4 F4 E4 G4 | P5 P4 M3 P5 |
| 2 | F4 E4 F4 G4 | m3 M2 m3 P4 |
| 3 | A4 G4 A4 B4 | M3 M2 M3 A4 |
| 4 | C5 B4 C5 B4 | m6 P5 m6 P5 |
| 5 | E5 D5 C5 B4 | M6 P5 P4 M3 |
| 6 | C5 B4 A4 G4 | P5 A4 M3 M2 |
| 7 | F4 G4 A4 B4 | m3 P4 P5 M6 |
| 8 | C5 | P8 |

不協和は9音。第2小節の E4、第3小節の G4 は協和音へ戻る刺繍音で、残りは同方向に順次進行する経過音です。第5小節第3拍の C5 も、D5–C5–B4 の経過音として成立します。第3・6小節の増4度は弱拍の経過不協和であり、増4度の掛留を認めることとは別です。第4→5小節の B4→E5 は完全4度の上行後に D5 へ下行して回復します。E5 は唯一の最高音。強拍の同族完全音程連続はなく、採点対象外とした前小節の特定弱拍と着地点の追加比較にも、この解答は抵触しません。最後は定旋律 D4→C4 と対旋律 B4→C5 の反行終止です。

### 第4種

定旋律は、この種の準備と解決に合わせた専用の自作旋律 C4 D4 E4 F4 G4 E4 D4 C4。対旋律の発音開始順は C5 B4 G5 F5 E5 C5 B4 C5 です。第1〜6音は各小節の第3拍から次小節前半まで保持し、第7音は二分音符、第8音は全音符です。

| 小節 | 第1拍の対旋律 / 第3拍の対旋律 | 垂直音程（第1拍 / 第3拍） |
| --- | --- | --- |
| 1 | 休符 / C5 | — / P8 |
| 2 | C5（保持） / B4 | m7 / M6 |
| 3 | B4（保持） / G5 | P5 / m10 |
| 4 | G5（保持） / F5 | M9 / P8 |
| 5 | F5（保持） / E5 | m7 / M6 |
| 6 | E5（保持） / C5 | P8 / m6 |
| 7 | C5（保持） / B4 | m7 / M6 |
| 8 | C5（全音符） | P8 |

第2・5・7小節の7–6、第4小節の9–8が、協和準備と下行順次解決を持つ不協和掛留です。第3・6小節の強拍は協和のまま保持します。第1拍同士、第3拍同士に同族完全音程の連続はありません。B4→G5 の上行短6度は F5 への下行順次進行で回復し、G5 は唯一の最高音。音域は B4–G5 の短6度、最大声部間隔は短10度です。第7小節の C5保持→B4→最後のC5 は、定旋律 D4→C4 に対する終止の7–6掛留です。

### 第5種

定旋律は C4 D4 E4 F4 G4 E4 D4 C4。対旋律の発音開始順は G4 F4 E4 F4 A4 G4 A4 G4 A4 B4 D5 C5 G4 A4 B4 C5。リズムを含めた同時発音の確認は次のとおりです。

| 小節 | 拍: 対旋律 | 垂直音程 |
| --- | --- | --- |
| 1 | 1: G4（二分）、3: F4（四分）、4: E4（四分） | P5 P4 M3 |
| 2 | 1: F4（二分）、3: A4（次小節前半まで保持） | m3 P5 |
| 3 | 1: A4（保持）、3: G4（二分） | P4 m3 |
| 4 | 1: A4（四分）、2: G4（四分）、3: A4（二分） | M3 M2 M3 |
| 5 | 1: B4（二分）、3: D5（次小節前半まで保持） | M3 P5 |
| 6 | 1: D5（保持）、3: C5（四分）、4: G4（四分） | m7 m6 m3 |
| 7 | 1: A4（二分）、3: B4（二分） | P5 M6 |
| 8 | 1: C5（全音符） | P8 |

第1小節の F4 は経過音、第4小節の G4 は刺繍音です。第3小節の A4→G4 は4–3、第6小節の D5→C5 は7–6掛留で、どちらも前小節第3拍で協和として準備しています。第6小節の C5→G4 の完全4度下行は、次の A4 への上行順次進行で回復します。最高音 D5 は1回、声部間隔は最大短7度。隣接区間、第1拍同士、第3拍同士に同族完全音程の連続はありません。最後は B4→C5 と D4→C4 の反行終止です。
