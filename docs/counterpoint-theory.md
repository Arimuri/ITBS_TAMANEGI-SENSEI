# 第1種トレーナーの理論・出典・検証

確認日: 2026-10-10。対象は `fux_inspired_two_voice_v1`、プロファイル版 `1`。

このプロファイルは、公開教材を参考に作った本アプリ固有の学習規則です。フックス原典や特定学校の採点基準を完全再現するものではありません。第1種の2声、長調、4/4の全音符1対1に限定します。規則適合は音楽的な完成度の点数ではありません。

## 理論資料と採用方針

- Kris Shaffer / Mark Gotham, [Open Music Theory: First-Species Counterpoint](https://viva.pressbooks.pub/openmusictheorycopy/chapter/first-species-counterpoint/): 上声での開始は完全同度・5度・8度、下声では完全同度・8度。終止は主音の同度または8度へ反行の順次進行。途中の同度、声部交差、前後時点をまたぐ声部の重なりを避ける。これらを本プロファイルの必須条件に採用します。
- Robert Hutchinson, University of Puget Sound, [Music Theory for the 21st-Century Classroom §30.2](https://musictheory.pugetsound.edu/mt21c/FirstSpecies.html): 第1種の垂直協和、終止、許容する旋律跳躍を参照。長短3度、完全4度・5度・8度、上行短6度を跳躍の許容集合とし、順次進行と併せて必須条件に採用します。短調・旋法では導音処理が必要な場合がありますが、今回の課題には適用対象を広げません。
- [Open Music Theory: Composing a cantus firmus](https://openmusictheory.github.io/cantusFirmus.html): 旋律の幅、最高音、跳躍後の反行順次進行を参照。本アプリではこれらを学習上の警告とし、合否と分けます。教材にある動機反復などの全項目を自動検査するわけではありません。

教材の本文や譜例を転載せず、規則の事実を参照して独自の日本語説明と課題を作成しています。Open Music Theory は各ページに CC BY-SA 4.0、Puget Sound の教材は [GNU Free Documentation License](https://musictheory.pugetsound.edu/mt21c/appendix-gfdl.html) の表示があります。これらは理論資料の利用条件であり、アプリの依存ライブラリのライセンスとは別です。

## 明示した独自の選択

次の点では、上記の厳格な第1種教材より許容範囲を広げています。課題画面のルール一覧が実際の判定基準です。

| 項目 | 本プロファイルの扱い |
| --- | --- |
| 連続完全5度・8度 | 同方向に両声が動く場合をエラー。5度と12度などの複音程も同じ族として扱う。静止した同じ2音を連続進行として重複計上しない。 |
| 直接・隠伏進行 | 同方向に完全音程へ到達し、上声が3度以上跳躍するとエラー。上声が長短2度で順次進行する場合は `direct_step_perfect` の警告。教材の厳格な禁止条件とは異なる。増1度・増2度などは旋律音程や調の規則で扱う。 |
| 反行による同族完全音程の連続 | 平行進行とは区別し、`contrary_perfect` の警告。教材では禁止される進行も、このプロファイルでは合否を左右しない。 |
| 重なりの境界 | 上声が前の下声より低くなる、または下声が前の上声より高くなる場合を対象とする。同じ高さへの到達は重なりとしない。 |
| 跳躍後の処理・同音反復・音域・最高音 | 教育上の警告。警告だけなら規則違反のない回答として扱う。 |
| 声部間隔 | 10度を超えたら警告。教材にある完全12度の上限を必須条件にはしない。 |
| 不完全協和音程の連続・旋律全体の輪郭 | 3度や6度の同族音程が4回以上続くこと、両声の最高音の同時出現、旋律の折り返し点が作る三全音、動機反復は自動判定しない。教材にはこれらの指針もあるため、合格後も耳と譜面で確認する。 |

異なる規則を選ぶときはプロファイルのバージョンを変更します。短調・教会旋法を加える場合は、調の使用音、導音の変化、終止型を課題文脈に応じて定義し、現状の長調終止を一律に流用しません。

## 音程計算と既存機能との境界

新しい採点器は `music21.interval.Interval` に綴りを持つ2音を渡し、音程の度数と性質を使います。例えば C–E は長3度ですが、同じ実音高を持つ C–F♭ は減4度です。半音数の剰余だけで同じ協和と扱いません。

公式 [Interval API](https://music21.org/music21docs/moduleReference/moduleInterval.html) では `simpleName` はオクターブを同度へ縮約し、`semiSimpleName` は8度を保持します。実際の同度、終止の実際の8度、複音程を含む完全音程族を用途別に区別する必要があります。

旧CLIの `critique/rules/species` はMIDI向けの半音数・beatモデルで、同時位置にない音を読み飛ばす処理もあります。トレーナーの入力完成検査、綴り、固定ID、整数tickとは契約が違うため、既存の採点設定を置き換えず、独立した追加モジュールで扱います。旧CLIの音高ラベルは中央C = C3、内部標準表記は C4 = MIDI 60。表示名だけを変えて、再生音高や譜面を移調しません。

## 課題の独立確認

課題と検証用解答は本実装のための自作素材です。検証用解答はAPIの課題一覧には含めません。採点は検証用解答との一致比較を使わず、各規則で行います。

以下の表は採点器から合否を転記するためのものではなく、音列から独立に照合した記録です。音名は内部標準表記（中央C = C4）です。

| 課題 | 定旋律 | 検証用対旋律 | 下声から上声への垂直音程 |
| --- | --- | --- | --- |
| `species1-c-above` | C4 D4 F4 E4 G4 F4 D4 C4 | C5 B4 D5 C5 B4 A4 B4 C5 | P8 M6 M6 m6 M3 M3 M6 P8 |
| `species1-g-above` | G3 A3 C4 B3 E4 D4 B3 C4 A3 G3 | D4 C4 E4 F♯4 G4 A4 G4 E4 F♯4 G4 | P5 m3 M3 P5 m3 P5 m6 M3 M6 P8 |
| `species1-f-below` | F4 G4 A4 C5 B♭4 G4 E4 F4 | F4 B♭3 C4 A3 G3 B♭3 G3 F3 | P1 M6 M6 m10 m10 M6 M6 P8 |

`P` は完全、`M` は長、`m` は短。音符ごとの独立確認は次のとおりです。

- 3題とも全音が調号内、全垂直音程が協和、開始・終止が指定条件内。途中の実音同度、声部交差、前後をまたぐ重なりはありません。同じ高さへ近づく境界はありますが、越えていません。
- C の終止は D4→C4 に B4→C5、G は A3→G3 に F♯4→G4、F は E4→F4 に G3→F3。いずれも導音の半音上行と第2音の全音下行です。
- C の途中には完全音程がなく、G の第4・6小節の完全5度はいずれも反行で到達します。F は最初の完全同度と最後の完全8度だけが完全音程です。連続完全音程や直接進行はありません。
- 対旋律の最高音は C が第3小節 D5、G が第6小節 A4、F が第1小節 F4 で、それぞれ1回。定旋律の最高音は順に第5、第5、第4小節なので、両声の頂点も分かれています。F の頂点は冒頭ですが、採用規則では頂点の小節位置を限定していません。OMT の定旋律教材が述べる、途中の頂点へ上行して終わりへ下行する弧状の輪郭も推奨として聴き比べる余地があります。
- 対旋律の幅は順に完全4度、長6度、完全8度。F の冒頭は完全5度下行ですが、直後の長2度上行で回復しています。他の旋律音程は2度または3度で、隣接反復や同方向への連続跳躍はありません。定旋律も8〜10音、主音に始まり主音に終わり、唯一の最高音を持ち、旋律の幅は8度以内です。
- 3題とも3度族または6度族が4回以上続く区間はなく、対旋律の折り返し点が作る三全音もありません。これは採用規則の合否に加えて行った照合であり、唯一の模範解答や音楽的品質の保証を意味しません。

採点器のテストで各解答が合格することに加え、以上の音列・垂直音程・進行方向の照合を行っています。検証用解答が唯一の答えという意味はありません。
